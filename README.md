# Photoshop for Newcomers

A comprehensive beginner's guide to Adobe Photoshop.

## 📖 Read the Book

**[View the online book here →](https://turboaristocrat.github.io/Photoshop-Tutorial/)**



## Chapters

1. **Welcome to Adobe Photoshop** — Introduction, installation, and first document
2. **Understanding the Interface** — Workspace tour and customization
3. **Basic Tools & Techniques** — Move, select, paint, and crop
4. **Layers & Masks** — Non-destructive editing fundamentals
5. **Adjustments & Filters** — Color correction and effects
6. **Saving & Exporting** — File formats and output

## 🚀 Deploying to GitHub Pages

1. Push this repository to GitHub
2. Go to your repo's **Settings → Pages**
3. Under "Source", select **Deploy from a branch**
4. Choose the `main` branch and `/ (root)` folder
5. Click **Save**
6. Wait a few minutes, then visit `https://YOUR_USERNAME.github.io/Photoshop-Tutorial/`
